## How maker and taker fees affect the result

The order’s execution determines whether the maker or taker rate applies.

A market order usually executes against existing orders and is therefore commonly charged at the taker rate. A limit order may receive the maker rate if it rests on the order book, but it can receive the taker rate if it matches immediately.

This distinction matters because the difference between the maker and taker rate can be larger than the value of a small referral rebate. Before submitting an order, check the fee information in the trading interface rather than relying on a generic fee table.

OKX says the order-placement panel shows the applicable maker and taker fee for the current trading pair. The final fee can still depend on the actual execution, including partial fills and the price at which the order fills.

For futures and perpetual contracts, the trading fee is only one part of the cost. Funding fees may apply, and forced liquidation can create additional charges. OKX also lists expiry settlement fees for certain futures products.
